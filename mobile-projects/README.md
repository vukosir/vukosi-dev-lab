# Mobile projects

Android, and anything cross-platform such as Flutter or React Native.

Commit the source, not the build output. `.apk` and `.aab` files are already
ignored by the root `.gitignore`; attach them to a GitHub Release instead if you
need to share a build.

Keep `local.properties` and any signing keystore out of the repo. Both leak
paths and secrets.

Each project README should say which minimum SDK it targets and how to build it.
