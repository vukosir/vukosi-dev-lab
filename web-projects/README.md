# Web projects

Anything that runs in a browser: static sites, single-page apps, dashboards,
landing pages, browser tools.

Give each project its own folder. If the entry file is called `index.html`, the
project can be served live from GitHub Pages at
`/vukosi-dev/web-projects/PROJECT-NAME/` with no build step.

## In here

- **currency-converter** Live mid-market rates for 160+ world currencies with a
  built-in scientific calculator, equation solver and money tools. Single HTML
  file, no dependencies, no build.
